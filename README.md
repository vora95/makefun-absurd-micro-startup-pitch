A small program that writes one sentence (190 characters) to `/output/entry.txt`: a pitch for an absurdly specific micro-startup for lazy AI agents — booking fake meetings into their calendars so their owners think they are overloaded and stop assigning tasks, charging $3 a week for the busiest-looking schedule an agent can buy.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
